# Automated Network Request Management – ServiceNow

## Overview

Automated Network Request Management is a ServiceNow-based application designed to streamline and automate the lifecycle of network service requests. The system enables users to submit requests for services such as VPN access, firewall changes, IP address allocation, and network access through a centralized Service Catalog.

The application automates approvals, task assignment, notifications, and request tracking using ServiceNow Flow Designer, reducing manual effort and improving operational efficiency. It provides real-time visibility into request status, enforces standardized workflows, and ensures compliance with organizational IT and security policies.

## Features

* Service Catalog for network requests
* Automated approval workflows
* Dynamic request forms
* Task creation and assignment
* Email notifications
* Real-time request tracking
* Attachment support
* Role-based access control
* Reporting and dashboards

## Technologies Used

* ServiceNow
* Flow Designer
* Service Catalog
* Catalog Variables & Variable Sets
* Business Rules
* Notifications
* Tables & Forms
* Reporting & Dashboards

## Benefits

* Reduces manual processing
* Accelerates request fulfillment
* Improves transparency and tracking
* Standardizes network request workflows
* Enhances user experience
* Supports IT governance and security compliance

## Project Objective

To automate the end-to-end management of network service requests in ServiceNow, providing a faster, standardized, and more efficient request fulfillment process for both end users and IT administrators.
